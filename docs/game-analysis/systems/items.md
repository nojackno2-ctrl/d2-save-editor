## 2. 品質判定順序與 MF 衰減公式

當確定掉落裝備時，先抽出底材，隨後進行獨立的品質骰：

### 品質檢驗判定鏈 (Quality Roll Order)

品質判定按以下順序嚴格**依序嘗試**：
1. **暗金 (Unique)**：嘗試成功則為暗金；失敗進入下一步。
2. **符文之語 (Runeword)**：嘗試成功則直接掉落已鑲嵌完成之符文之語；失敗進入下一步。
3. **套裝 (Set)**：嘗試成功則為綠色套裝；失敗進入下一步。
4. **稀有 (Rare)**：嘗試成功則為黃色稀有；失敗進入下一步。
5. **魔法 (Magic)**：嘗試成功則為藍色魔法；失敗進入下一步。
6. **普通 (Normal)**：上述皆失敗時為白/灰底材。
7. **保底提升**：最後依來源保底品質（如幕末魔王保底 Rare、冠軍保底 Magic）提升至不低於保底品質。

### 魔法尋寶率 (MF) 邊際效應公式

有效 MF 公式（\`i9\`，\`I新:875600\`）：
$$\text{EffectiveMF}(MF, K) = \left\lfloor \frac{\max(0, MF) \times K}{\max(0, MF) + K} \right\rfloor$$

| 品質等級 | 衰減因子 $K$ | 說明 |
|---|---:|---|
| **Unique (暗金)** | **250** | 衰減最劇烈，MF 1000 時有效 MF 僅 200 |
| **Runeword (符文之語)** | **250** | 與暗金共用相同的強力衰減 |
| **Set (套裝)** | **500** | 衰減次之 |
| **Rare (稀有)** | **600** | 衰減較緩 |
| **Magic (魔法)** | $\infty$ (無衰減) | 線性套用非負原始 MF 值 |

### 判定式運算流程

令底材之 $qlvl$、掉落來源之 $ilvl$：
1. $a = \left( \text{ratio} - \text{trunc}\left(\frac{ilvl - base.qlvl}{\text{divisor}}\right) \right) \times 128$
2. $b = \max\left(\min, \left\lfloor \frac{a \times 100}{100 + \text{EffectiveMF}} \right\rfloor\right)$
3. $D = b - \left\lfloor b \times \frac{\text{round}(1024 - 1024 / \text{boost})}{1024} \right\rfloor$
4. 擲骰檢驗：若 $\lfloor \text{random} \times D \rfloor < 128$，則品質判定成功！

預設品質常數表（\`Rye\`，\`I新:699307\`）：
- 一般底材：Unique (400 / 1 / 6400), Set (160 / 2 / 5600), Rare (100 / 2 / 3200), Magic (34 / 3 / 192)
- 職業專屬底材：Unique (240 / 3 / 6400), Set (120 / 3 / 5600), Rare (80 / 3 / 3200), Magic (17 / 6 / 192)

## 3. 底材與詞綴等級 (alvl) 計算

### 詞綴等級公式 (\`L9\`，\`I新:885900\`)

$$n = \max(\min(ilvl, 99), qlvl)$$
- 若底材具備 $\text{magicLevel} > 0$（例如頭飾類 Circlet: 3, Coronet: 8, Tiara: 13, Diadem: 18；部分法杖為 1）：
  $$alvl = \min(99, n + \text{magicLevel})$$
- 否則（無 magicLevel）：
  - 若 $n < 99 - \lfloor qlvl / 2 \rfloor$：
    $$alvl = n - \lfloor qlvl / 2 \rfloor$$
  - 否則：
    $$alvl = 2n - 99$$
  最後將 $alvl$ 截斷於上限 99。

### 詞綴抽取數量與規則

- **魔法物品 (\`R5\`)**：50% 機率嘗試前綴；成功再 50% 嘗試後綴，否則必嘗試後綴；兩者皆未抽中時重新補抽前綴。最終分布為 25% 純前綴、50% 純後綴、25% 前後綴雙全。
- **稀有物品 (\`_xe\`)**：從陣列 \`[3, 4, 4, 5, 5, 5, 6, 6]\` 等機率抽取目標詞綴總數。即 3 個 (12.5%)、4 個 (25%)、5 個 (37.5%)、6 個 (25%)。前後綴各自上限為 3，同組（\`kind:group\`）互斥。技能大板／職業專屬前綴共用 \`prefix:125\`，權重加成 26 倍。

## 4. 套裝與暗金全收集 (Holy Grail) 機制

- **候選清單篩選**：
  暗金 (\`o9\`) 與套裝 (\`qSe\`) 判定成功後，並非強制綁定抽出的底材，而是從全球合格資料庫中重新篩選：
  $$\text{item.lvl} \le ilvl \quad \text{且} \quad \text{item.base.qlvl} \le W8(treasureLevel)$$
- **掉落權重正規化**：
  - 同底材暗金以 $\sqrt{\text{rarity}}$ 正規化。
  - 若該暗金等級低於關卡等級過多（$\text{item.lvl} < ilvl - 25$），權重降低至 0.25 倍。
  - 當存在當前遊玩職業專屬候選時，75% 機率優先從職業清單中抽取。
- **降級保護 (Fallback)**：
  若當前條件下無符合等級之暗金或符文之語，**自動退回為稀有品質 (Rare)**；若無符合套裝，則**退回為魔法品質 (Magic)**。
- **收集追蹤**：
  透過模組 \`uniquesTab-Dog15Mdz.js\` 追蹤存檔中的全暗金與全套裝達成度（聖杯挑戰），重複掉落已收集項目依然會正常掉落並允許裝備。

## 5. 符文之語生成機制 (\`rCe\`)

在 D2 Survivors 中，**獨立的符文 (Runes) 不會單獨作為地表雜物掉落**。符文之語直接以完整裝備形式產生：

- **觸發函式**：\`rCe\` (\`I新:880000\`)
- **底材相容性要求**：
  - 底材類型必須與該符文之語相容（如 Enigma 須為 Armor，Grief 須為 Sword/Axe）。
  - 底材之 $qlvl$ 必須達標。
  - 底材最大孔數必須滿足符文數（依 $ilvl \le 25, 26\sim 40, >40$ 查表 \`qye(base, ilvl) \ge \text{runes.length}\`）。
- **無形機率 (Ethereal)**：
  若所選底材具備耐久度（武器、防具），則有 **5% 機率產生為無形 (Ethereal)**。
- **符文序號權重衰減**：
  候選符文之語按其最高級符文序號給予權重：
  $$\text{Weight} = 1.04^{-\text{highestRuneIndex}}$$
  越高級之符文之語（如包含 Zod, Cham, Jah, Ber 者）權重呈指數型遞減。
