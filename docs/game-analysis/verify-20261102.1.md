# 20261102.1 更新與工具相容性

資料來源為官方 `https://d2survivors.lol/changelog.json` 第一筆，以及 `Game-Ba9RuE4G.js`、`saveTransfer-C-ucl_ha.js`、`itemArt-CUOhw0kt.js`。以下記錄截至 2026-11-02 的證據，不能取代完整實機驗收。

## 遊戲變更

- 每名角色有兩組武器，只有目前組的屬性、技能與靈氣生效；預設 W、物品欄按鈕或手把按鍵可切換。
- 鍵盤按鍵可以重新綁定，預設以方向鍵或滑鼠移動；選項可恢復 WASD。
- 恐怖層 40 以上，每層尋寶與金幣加成由 2% 改為 1%；100 層以上掉落的物品售價不再繼續增加。
- 職業專屬底材的符文之語保留底材屬性，既有存檔載入時會補上；裝備施放的技能不再沿用角色的進化與變體。
- 修復部分裝備屬性、掉落過濾、藥水、進度及手機顯示與記憶體問題，完整內容以官方更新紀錄為準。

## 已核實的工具變更

- 遊戲的 `equippedByClass` 保存目前組，`weaponSets` 保存未啟用組及 `active`（1 或 2）。修改器切換演算法與原版 36 種狀態比對一致。隔離網頁測試將一面遊戲產生的 Pelta Lunata 放入亞馬遜備用組並寫入，遊戲冷啟後讀回，再以遊戲原生切換成功穿戴並保存；其他職業、雙持與雙手組合尚未驗證。
- 自動選卡的候選產生器改由 `saveTransfer` 匯出 `va`，武器解析由 `itemArt` 匯出 `A`。輔助器依目前遊戲模組辨識函式，無法辨識時封鎖操作。技能欄滿時原版會先隨機選一個替換候選；一般升級且原版抽樣池含替換卡時，輔助器另外擷取隨機前的替換清單。特殊選卡模式仍採保守判斷；尚未實戰驗證。
- 選卡優先呼叫遊戲回呼，回呼不可用時優先讀取遊戲記憶體中的鍵位，再以 `d2s:keys` 備援。隔離官方網頁測試已觀察自然升級觸發原版回呼；另將遊戲內選卡鍵設為 Z／X／V、儲存值刻意改為 Q／R／T，於既有選卡畫面啟動輔助器後仍成功以 KeyZ 選卡。僅測亞馬遜，未涵蓋所有特殊鍵位與選卡模式。
- 物品引擎補回技能變體表特徵碼，並修正職業底材符文之語驗證因隨機屬性長度不同而發生的例外。隔離測試對目錄 574 筆分別以一般及最高值模式各生成一件，遊戲與工具檢查均無錯誤；尚未獨立證明每件物品的全部理論最大值能同時合法存在，亦未涵蓋全部底材與種子。
- 新增 112 條繁中譯文；原版翻譯器對 11937 條直接字串比對僅餘刻意保留的 DPS。動態樣板和實際畫面不在此比對範圍。
- 原版 `world.gold` 是本局累積金幣，輔助器已停止覆寫該欄；隔離網頁戰鬥測試中，總額到 90 億時開關關閉、倍率由 999999 還原 1.25，本局金幣保留。尚未驗證大額單次掉落跨過門檻的情況。
