# 舊版遊戲辨識與封鎖

依使用者要求，工具包僅針對最新版修正；以下舊版測試用於辨識與封鎖，並不表示支援舊版。2026-11-02 以本機留存的三版遊戲程式區塊，在獨立 Electron 設定檔與暫存目錄測試，沒有讀取或寫入使用者存檔。版本以既有分析紀錄對照遊戲主程式雜湊檔名；物品資料使用目前本機的 itemstats，因此不代表舊版原始物品資料的完整比對。

三版必要物品引擎特徵碼均命中。每版載入原版物品模組後，分別生成 Pelta Lunata、Civerb's Ward、Ancients' Pledge，並額外生成 20 件 Vortex Shield／Ancients' Pledge；遊戲 `itemFault` 與修改器 `validateItems` 均無問題。七職業均可讀取技能變體。這是有限的引擎冒煙測試，不代表所有底材、品質、詞綴或存檔格式皆已驗證。

修改器依實際載入的遊戲版本判斷：網頁版核對實際執行的遊戲主程式與物品、存檔模組；桌面版讀取安裝包內的 `changelog.json`。舊版、其他版本或版本無法確認時，封鎖遊戲存檔寫入與遊戲相依的物品引擎，仍可讀取資料；雙武器組入口也不會啟用。這台電腦的桌面遊戲安裝包顯示為 `20261101.1`，在更新前應被封鎖。隔離測試涵蓋修改器介面、桌面 IPC 與網頁後端的封鎖；尚未對使用者遊戲存檔實際操作。
