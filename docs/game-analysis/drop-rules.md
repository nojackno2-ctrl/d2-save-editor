## 品質、MF、收藏

- 主流程 `I5→VSe→HSe→LSe`（I:839412,875000–877000）先抽底材供品質判定，依序獨立嘗試暗金 → 符文之語 → 套裝 → 稀有 → 魔法 → 普通，再提升至來源最低品質。後段實際機率須乘前面各次失敗機率。片段：`a('unique')?'unique':a('runeword')?...`。
- `i9(MF,K)=floor(max(0,MF)*K/(max(0,MF)+K))`。暗金及符文之語 K=250、套裝 500、稀有 600；魔法用非負 MF。令 `a=(ratio-trunc((ilvl-base.qlvl)/divisor))*128`、`b=max(min,floor(a*100/(100+有效MF)))`、`D=b-floor(b*round(1024-1024/boost)/1024)`；判定 `floor(random*D)<128`。正整數 D 時為 `min(1,128/D)`，其他邊界以原式為準（I:875600）。
- 預設 version 1 比率 `ratio/divisor/min`（`Rye`，I:699307）：一般底材暗金 400/1/6400、套裝 160/2/5600、稀有 100/2/3200、魔法 34/3/192；職業底材依序 240/3/6400、120/3/5600、80/3/3200、17/6/192。載入的 `R.itemRatio` 可覆蓋預設，實際載入值未確認。
- `KS`（I:358100）暗金 boost：冠軍 1024/224、特殊頭目 8、幕末任務設定 1024/29、幕末一般設定 1024/41；稀有 boost 冠軍／特殊頭目 1024/224、一般怪 3。暗金 boost 在地獄乘 1.5、恐懼層乘 1.9；套裝使用暗金 boost 的 0.2 倍、符文之語 0.25 倍。這是公式輸入，非直接機率倍率。
- 暗金 `o9/WSe`、套裝 `qSe/KSe`（I:878000）從整個合格清單另選，不固定剛抽的底材：`lvl<=ilvl` 且底材 `qlvl<=W8(treasureLevel)`。暗金同底材用 `sqrt(USe[name]??1)` 正規化；`lvl<ilvl-25` 再乘 0.25。有適職候選時 75% 用適職清單。套裝以同底材 rarity 正規化。

## 詞綴、無形、孔數

- `R5`（I:840400）魔法物品 50% 嘗試前綴；成功再 50% 嘗試後綴，否則必嘗試後綴；均失敗再嘗試前綴。候選充足時恰前綴／恰後綴／兩者為 25%／50%／25%。戒指、項鍊、頭環普通品質升魔法；護符強制魔法。
- 稀有 `_xe`（I:841100）從 `[3,4,4,5,5,5,6,6]` 等機率選目標數，3／4／5／6 個為 1/8、2/8、3/8、2/8；前後綴各最多 3，候選不足可更少，自動詞綴另計。
- `L9`（I:885900）：`n=max(min(ilvl,99),qlvl)`；有 magic level 時 `alvl=min(99,n+magicLevel)`；否則當 `n<99-floor(qlvl/2)` 用 `n-floor(qlvl/2)`，否則用 `2*n-99`，再封頂 99。頭環 magic level 3／8／13／18；杖、法杖、寶珠一般為 1，部分例外為 0。
- `ECe/V9/R9`（I:886000）檢查種類、職業、詞綴等級及 maxLevel；稀有排除 magicOnly；同 `kind:group` 互斥，職業技能前綴共用 `prefix:125`。D2 詞綴依 frequency 加權，有 magic level 底材用 `level*frequency`，skiller 再乘 26。數值 `min+floor(random*(max-min+1))`，兩端皆可，alike 共用數值。自動詞綴 `rxe`（I:809000）依底材及 alvl 篩選，稀有排除 magicOnly。
- 符文之語底材可耐久時 5% 無形（`rCe`，I:880000）；`qye`（I:701308）按 ilvl ≤25、26–40、>40 選底材資料最大孔數供相容判定。一般裝備無形率、實際孔數擲法及完整 +skills 限制未確認。
