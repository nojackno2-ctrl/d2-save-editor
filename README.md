# D2 倖存者 存檔修改器

《D2 Survivors》（d2survivors.lol）的非官方存檔修改器，介面全繁體中文。物品直接使用遊戲本身的產生器製作，數值範圍與遊戲一致。

- **網頁版（電腦／手機）**：<https://nojackno2-ctrl.github.io/d2-save-editor/>
- **Windows 桌面版**：到 [Releases](https://github.com/nojackno2-ctrl/d2-save-editor/releases) 下載 `D2.exe`（可攜版，免安裝）

> ⚠️ 修改前請先備份存檔。本工具與遊戲官方無關，使用風險自負。

## 功能

| 頁面 | 說明 |
|---|---|
| 物品 | 瀏覽角色、傭兵、倉庫、背包、護身符欄的物品；編輯底材、品質、屬性，複製或移動物品；顯示每個屬性的遊戲範圍 |
| 製作裝備 | 自選底材、品質與屬性訂製裝備；列出底材可用的詞綴範圍，新增屬性預設最大值；名稱依遊戲詞綴規則決定 |
| 裝備庫 | 從遊戲全部暗金、套裝、符文之語中挑選製作，可一次製作多件、取最高數值 |
| 帳號 / 強化 | 金幣、光之碎片、傭兵欄；恰西永久強化與額外強化；各角色技能修改、重置次數、恐怖區域 |
| 反修改偵測 | 依遊戲本身的檢查規則（金幣上限、物品合法性、角色等級、簽章、匯入痕跡等）掃描存檔並一鍵修正 |
| 存檔管理 | 快照備份、還原、建立全新存檔 |
| 原始 JSON | 直接檢視與編輯存檔內容 |
| 設定 | 「解除修改限制」：超過正常上限的數值倍率、不限製作數量 |

屬性範圍來自統一的資料庫：暗金、套裝、符文之語取遊戲產生器的上下限；魔法、稀有等其他品質取底材可用詞綴的範圍。

## 網頁版使用方式

1. 打開[安裝頁](https://nojackno2-ctrl.github.io/d2-save-editor/)，複製書籤程式碼並加入書籤（頁面上有 Android、iPhone 與電腦的步驟）。
2. 到 [d2survivors.lol/play](https://d2survivors.lol/play/)，停在**主選單**。
3. 點書籤開啟修改器（Android 需在網址列輸入書籤名稱再點選）。
4. 修改後按「寫入存檔」，再按「關閉」，遊戲會重新載入。

網頁版直接讀寫瀏覽器裡的存檔，不經過遊戲的匯入功能，不會留下匯入紀錄。第一次開啟需要連網載入遊戲程式。

## 桌面版使用方式

1. 下載 `D2.exe`，可對照 `SHA256SUMS.txt` 確認檔案完整。
2. 關閉遊戲後執行修改器，它會讀取已安裝遊戲的存檔。
3. 修改後按「寫入存檔」，每次寫入前會自動備份。

執行檔未經程式碼簽署，Windows 可能跳出 SmartScreen 警告，請選「其他資訊 → 仍要執行」。

## 注意事項

- 修改套裝、魔法、稀有物品的屬性後，遊戲可能判定為「Not legit」（只影響排行榜），可到「反修改偵測」頁處理。
- 自訂任意屬性不一定有對應的遊戲名稱；無法唯一判定名稱時會提示，不會猜測。
- 「可用詞綴範圍」是此底材可能出現的詞綴，並非都能同時出現。
- 遊戲更新後部分功能可能失效，請回報問題。

## 開發

```bash
cd editor
npm install
npm start          # 執行桌面版
npm run dist       # 封裝 Windows 可攜版
node build-web.js https://nojackno2-ctrl.github.io/d2-save-editor/   # 產生網頁版到 ../web
```
