存檔修改器功能

數值資料庫與遊戲邏輯完全同步，支援瀏覽、客製訂製與快照備份

🗡️ INSPECT

物品瀏覽與自訂

即時檢視角色、傭兵、倉庫、背包與護身符欄。可直接編輯裝備底材、品質與數值屬性，完整顯示各屬性的遊戲正常數值範圍。

⚒️ AFFIX_CRAFT

裝備精工訂製

魔法／稀有裝備清晰劃分「前綴」、「後綴」與「固有屬性」三區，嚴格計算詞綴上限。新增詞綴預設帶出最大合法值，名稱遵循原版詞綴規律。

👑 UNIQUE_DB

全裝備庫製作

一鍵查閱全遊戲暗金、綠色套裝與符文之語，支援多件製作與一鍵頂標（暗金／套裝／符文之語製作需開啟解除限制開關）。

💰 CHAR_UPGRADE

帳號與強化調整

安全調整金幣、光之碎片、傭兵欄解鎖、恰西永久與額外強化，以及全角色技能等級、技能重置次數與恐怖區域設定。

🛡️ COMPLIANCE

反修改偵測與合規檢查

掃描存檔中的金幣上限、詞綴數、稀有+技能規則、等級點數匹配度與簽章，主動抓出可能被排行榜拒絕的異常項目。

💾 BACKUP_IO

存檔管理與原始 JSON

支援多槽位快照備份、即時還原及建立新存檔；內建高階 JSON 編輯器供資深玩家直接檢視微調資料。

遊戲輔助器與三大自動模式

不修改遊戲底層記憶體或任務旗標，僅模擬原版操作與輸入，安全又聰明

MODE 01 // QUEST

任務模式

自動檢測任務進度並完成所有主線（如尋找卷軸、石塊陣救凱恩），打完巴爾回營地整備並循序開啟惡夢與地獄難度；18 項任務通關且升至 99 級後，無縫轉為固定地獄刷寶。

MODE 02 // FARMING

固定關卡模式

全自動重複刷特定指定難度（普通、惡夢或地獄）。自動開局、清圖、拾取、回營地整備販售，全天候穩定累積資源。

MODE 03 // LADDER

天梯模式

支援連續推關挑戰極限恐怖層數，或設定固定層數穩定刷取高階獎勵。依排行榜高手配點與換裝持續推進。

製作裝備與操作控制

製作裝備可依分類篩選底材，分別檢視前後綴範圍；可確定的複合詞綴會自動補入並同欄顯示，無法唯一判定時提示確認。遇到問題可輸出裝備設定供診斷。

戰鬥中可按「停止自動戰鬥」；設定面板的「立即停止輔助」關閉兩個輔助總開關，「全部關閉」另關閉細部開關與自動模式。部分已套用的遊戲修改可能持續至重新開始遊戲。

>

智慧戰鬥走位與閃避

實時計算怪物合計威脅，預判包圍空隙，重擊飛彈與近戰橫移閃避，依技能射程維持最佳輸出距離。

>

預判喝水與死亡保護

靠近魔王提早補血，預估致命傷害提早喝水；死亡保護預設關閉，觸發時以原版離場並停用自動推進；不保證生存，須手動重新開啟。

>

全自動換裝與天梯配點

參考全服天梯高手比例自動配點，自動辨識暗金/套裝最佳穿戴、自動使用任務獎品與阿卡拉技能洗點。

>

全圖吸取與自動整備

全圖吸經驗與自動撿裝，回營地自動交任務、存倉庫、賣垃圾、買藥水與恰西升級，流程一氣呵成。

大量實測數據

輔助器的每項調整都來自真實遊戲長時間掛機的結果

📈 CAMPAIGN

全新存檔一路推進

全新存檔的法師全自動打通普通（第五幕 82 級擊敗巴爾）與惡夢，推進到地獄第二幕；在地獄陣亡後會自動回惡夢練等。

🧪 35_RUNS

35 個存檔長跑

以 35 個存檔長時間實戰，修正精英判斷、閃避、換裝、配點、交任務等數十項行為；營地整備實測可自動賣裝、買穿皮甲並升級生命。

🏆 TOP_50

依排行榜高手配法

選卡、配點、技能變體與換裝參考排行榜各職業前 50 位玩家的實際配置，遊戲改版後重新抓取。

⚠️ 自動戰鬥並不完美

  • 不保證存活或通關：實測曾在惡夢撿物時被頭目一擊打掉 900 血、藥水用完時走進毒魔群陣亡；地獄難度仍常陣亡。
  • 最高難度連續失敗 3 次會自動回低一級刷，進度可能比手動慢。
  • 部分流程（讀法典、使用任務獎品、交伊尼弗斯卷軸、石陣鑰匙）尚未完整實測，可能需要手動處理。
  • 遊戲改版後可能有功能失效，畫面會提示「遊戲已更新」。
  • 建議偶爾查看狀況，長時間無人看管前請先備份存檔。

書籤安裝三步驟簡述

網頁版採用輕量書籤小程式（Bookmarklet），電腦與手機瀏覽器皆可免安裝使用

01

步驟 1：取得書籤代碼

前往網頁版安裝頁，點擊「📋 複製書籤程式碼」按鈕複製啟動代碼。

javascript:import('https://nojackno2-ctrl.github.io/d2-survivors-toolkit/d2edit.js?v='+Date.now())
02

步驟 2：加入瀏覽器書籤

電腦版：將安裝頁按鈕拖曳至書籤列，或新增書籤貼上網址。
手機版 (iOS/Android)：將任意頁存入書籤後編輯，將網址替換為代碼（注意保留開頭的 javascript:）。

03

步驟 3：開啟遊戲呼叫工具

進入 d2survivors.lol/play 點擊書籤載入。在遊戲中按下「暫停」，點擊畫面左上角「修改器」或左上角「輔助」即可開啟完整功能！

⚖️ 合規模式 vs. 解除限制說明

標準合規模式（預設）

完全遵循 Diablo II 原版生成與遊戲 10/20 排行榜規則（魔法 1前綴1後綴、稀有 2~6 詞綴且至多一條職業+技能、屬性點不超標、金幣與單次恰西花費低於 100 億）。依已知規則檢查，但不保證排行榜接受存檔。

⚠️ 但不保證絕對安全：遊戲隨時可能更新排行榜的檢查方式，也可能有未公開的偵測，修改過的存檔仍可能被排行榜拒絕、移除紀錄或停權，是否上傳請自行評估。

解除限制模式（單機爽玩）

若你只想在單人模式體驗毀天滅地的爽快感，可以在設定中打開「解除修改限制」。解除後裝備製作將不再受原版詞綴、數量與品質限制，允許自訂超越遊戲常規的神級裝備（此狀態存檔將無法上傳排行榜）。
